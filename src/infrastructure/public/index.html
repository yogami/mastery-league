How Fair Skill-Handicap Matchmaking Works

In a flat classroom game, everyone gets the same question. Advanced students coast; struggling students get knocked out in 20 seconds.

  • Progressive Topic Ladder: Topics build step by step (Equivalent Fractions leads into Unlike Denominators, Two-Step Equations, and Linear Inequalities).
  • Real-Time Skill Calibration: Every response updates each student's mastery score while filtering sub-1.2s random button mashing.
  • Fair-Handicap Survival: During Last-Student-Standing, each student receives a question matched right above their current baseline so everyone has an equal survival shot by beating their own next milestone.
